## Goal
Ship v0.2 Audit Quick Wins as **0.4.0**: bump the version, write the CHANGELOG, open one PR from `paul/milestone-v0.2` to main, and, after you merge it, push tag `v0.4.0`. ## Purpose
The README already pins 0.4.0 (07-01). release.yml only accepts a tag that is on `origin/main`, matches `package.json`, and has a dated CHANGELOG section. So the order has to be: merge, tag, publish. The window between merge and publish, when main's README points at an unpublished version, should be kept to minutes.
