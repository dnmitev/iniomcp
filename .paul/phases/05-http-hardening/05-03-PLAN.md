## Goal
Clear five deferred items, then release 0.3.1 and close v0.1 with a short deferred list.

## Purpose
- **Email length** is an input-validation gap at a trust boundary. Today the Inio API rejects an over-long email; our schema should reject it first, with a clear message.
- **Logger type:** Phase 5 left two Logger types (pino's in http.ts, ours in auth.ts). They should be one before more code depends on either.
- **Tooling:** every mutation run this session mutated the whole project, and there is a dev-dependency advisory.

## Output
- Schema change with tests.
- Logger refactor (no behaviour change).
- Tooling fixes.
- CHANGELOG entry and the 0.3.1 release.
</objective>
