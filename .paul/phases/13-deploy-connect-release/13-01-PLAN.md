<objective>
## Goal
The Helm chart can turn on OAuth sign-in with a few values and routes the metadata path. The docs explain the provider setup generically and how to add the server as a connector in Claude on the web, Desktop and mobile. 0.7.0 is released, and the owner signs in from claude.ai on the team instance.

## Purpose
This closes v0.4: business users without a local setup can use the hosted server from Claude's apps.

## Output
- Chart values `oauth.issuer`, `oauth.publicUrl` (default `https://<ingress.host>/mcp`), `oauth.audience`; env wiring; Ingress and HTTPRoute route `/.well-known/oauth-protected-resource`; CI validates and smoke-tests it
- docs/hosting.md "Sign-in with OAuth" section; new docs/setup/claude-web.md; README and Desktop guide point to it
- CHANGELOG [0.7.0], version and pins 0.7.0, PR, release
- Owner deployment checkpoint (provider config handed over privately)
</objective>

## AC-1: Chart
```gherkin

When the chart renders
Then the output is identical to 0.6.0 for the same values (no new env, routes or behaviour)
Given oauth.issuer is set

```
