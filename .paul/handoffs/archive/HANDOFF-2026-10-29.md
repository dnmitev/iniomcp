## Working Patterns That Worked

- **TDD loop:** QA (red) → developer (green) → reviewer, then mutation testing. Run the reviewer and mutation testing in parallel; both are read-only.
- **Before handing work to the next agent:**
  - give QA exact messages and result shapes up front;
  - check QA's assumptions against `openapi/inio.json` and against how `src/inio-client.ts` calls fetch (`fetch(url, init)`);
  - QA should lint with `npm run lint` (oxlint), not eslint.
- **Verifying a mutant is killed:** flip the line by hand, run the test file, then restore it. This is faster than re-running Stryker.
