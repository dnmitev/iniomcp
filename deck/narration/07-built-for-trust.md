This server was built to earn your trust. We ran an independent security audit that found 29 issues, and we fixed them. Version 0.4.0 strengthened authentication, corrected how write operations report their outcomes, and blocks malicious requests before they can do anything. Every release is tested against real Inio environments before it's published. The package includes verification records so you can confirm what you're installing actually came from our build process. For teams, you can set up one secured server that everyone shares, instead of each person managing their own credentials. This means your team gets consistent access and fewer configuration headaches.
