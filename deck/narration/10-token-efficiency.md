We designed the output for context efficiency. An invoice list item in raw form is about nine kilobytes. We compress that down to roughly seventy two tokens by returning only the summary fields you actually need. Detail responses drop empty values before redaction runs. Large workflow settings are opt-in, so you don't get stage distribution details unless you ask for them. Results are text only, with logs going to standard error. This keeps your token budget available for the data itself instead of wasting it on metadata or empty fields.
