The release process is production ready. We use a tag-driven pipeline with a live validation gate that tests against real Inio environments before publishing. The npm package includes supply chain provenance through trusted publishing, so you can verify where it came from. Docker images support AMD64 and ARM64, and they include Software Bill of Materials attestations. GitHub Actions handles everything: building, testing, running mutation gates, and publishing to both the npm registry and GitHub Container Registry. It's fully automated, auditable, and repeatable.
