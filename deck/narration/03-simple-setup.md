Getting started is straightforward. You need four environment variables: your client ID, client secret, the auth URL, and your API URL. Then you run one command. That's it. We published both an npm package and a Docker image so you can choose what fits your environment. The configuration works immediately in Claude Desktop, Cursor, and Visual Studio Code. You don't need to write integration code, deploy a service, or learn a new API. Four variables, one command, and you're asking questions about your Inio data in plain language.
