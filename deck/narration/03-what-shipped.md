We published two packages: an npm package and a Docker image. Setup is straightforward. You provide four environment variables: your client ID, client secret, the auth URL, and your API URL. Then you run one command. The package includes seven read tools for querying customers, invoices, pauses, and retry attempts. It also includes eleven write tools that are opt-in, giving you eighteen operations total. The read tools are enabled by default. The write tools require setting one environment flag to activate them.
