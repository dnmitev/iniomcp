The roadmap has four main items. First, we're adding more personal data redaction: organization numbers, consumer customer names, addresses, city, and free text fields. Second, we're building a write tool allowlist and a payment ceiling to limit the blast radius even further. Third, we're hardening the release path with SHA-pinned actions and image build provenance. Fourth, we'll move to the Inio organization npm scope and the company GitHub org once they're established. These are all about making the server more secure and production ready for larger teams.
