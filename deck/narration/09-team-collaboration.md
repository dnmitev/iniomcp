Version 0.3.0 added a shared HTTP server mode so teams can work together. All requests need a bearer token, which the server checks using constant-time comparison to prevent timing attacks. An origin allowlist blocks cross-site attacks by limiting requests to localhost or domains you approve. When the server restarts, it drains in-flight requests gracefully instead of cutting them off. This makes the server suitable for team deployments where multiple people share one instance, not just individual installations on each person's machine.
